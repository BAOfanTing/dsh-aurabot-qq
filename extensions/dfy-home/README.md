# 大肥鱼的家（Aurabot 扩展）

把大肥鱼住的那个 2.5D 小房间接进 Aurabot：**问她在哪，她能说出自己在家里哪个角落；要照片，她发一张第一视角截图到 QQ。**

场景来自配套的本地小游戏 `dfy-room`（Three.js 的房子 + 院子，109 段透明动画）：屋子分**卧室 / 客厅 / 厨房**
三间，外面是带泳池、大树秋千的**院子**，一共 21 个能点名的地点（床边、书桌、沙发、电视、灶台、餐桌、泳池、秋千…）。
它对外开了一组本机 HTTP 接口；这个模块只做"翻译"和"发图"，不改动插件内核。

## 她多会了什么

| 触发 | 她会做什么 |
| --- | --- |
| 有人问"你在哪""你在家干嘛呢" | `home_where`：说出在哪间屋子的哪个角落 + 那句台词 + 正在播的动作 |
| 有人说"给我看看你那边""发张照片" | `home_photo`：**真的发一张第一视角图**到当前聊天 |
| 有人问"床呢""厨房长什么样""带我去泳池" | `home_goto`：先走过去，再拍一张发出来，然后照实际位置说话 |
| 主人发 `/家`（`/home`、`/我的家`） | 回一句位置 + 附带一张第一视角 |

默认只有私聊发照片；群里只回文字位置，面板里打开「群里也发照片」才发。

## 安装

1. 把整个文件夹复制到 Aurabot 的用户模块目录：

```powershell
$dst = "$env:USERPROFILE\.dsh\plugins-data\aurabot\modules\dfy-home"
New-Item -ItemType Directory -Force $dst | Out-Null
Copy-Item .\* $dst -Recurse -Force
```

（Linux / Docker：目标目录是数据目录下的 `modules/dfy-home`，遵守 `DSH_HOME` / `AURABOT_DATA_DIR`。）

2. 打开 Aurabot 面板「扩展」页，确认列表里有「大肥鱼的家」并正在运行；再切到它的「大肥鱼的家」标签页。

## 面板

- **连接**：家的地址（默认 `http://127.0.0.1:5178`）、家的目录（填了才能一键启动）、群里是否也发照片、启动后是否自动开浏览器。
- **她现在在哪**：位置、描述、正在播的动作、页面开着没；下面是地点按钮，点一下她就走过去。
- **第一视角**：拍一张就在这里看（和发到 QQ 的是同一张）。
- **最近去过**：她这阵子串门的顺序。

「打开家」会：读「家的目录」→ 起 `node server.js <端口>` → 等端口通 → 打开默认浏览器。

## 前置：把家跑起来

```bash
cd <dfy-room 目录>
node server.js 5178
```

或者用面板里的「打开家」。第一次用建议先手动跑一次，确认 <http://127.0.0.1:5178/> 能打开、点「🏠 大肥鱼的家 → 📸 拍第一视角」能拍到照片。

## 页面没开着也能拍

`GET /api/home/shot` 发现没人开着页面时，dfy-room 那边会自己起一个无头 Chrome 现拍
（`scripts/shot.mjs`；找不到浏览器就回一条失败原因，模块会把它转成一句人话告诉对方）。
想关掉这个兜底：在跑 dfy-room 的环境里设 `DFY_NO_HEADLESS=1`。

## 依赖与边界

- 零 npm 依赖，只用 Node 自带 `fetch`（Node 20+；Aurabot 要求 22+）。
- 地址只允许本机（`127.0.0.1` / `localhost`），不接受外网地址，免得把她的视野发到别人的机器上。
- 所有位置、动作、照片都来自 dfy-room 的网页，这里不编造；页面没开时会明说"这是最后一次记下的位置"。
- 图片走 `base64://` 直接发给 QQ（Aurabot 的 `fetchImage` 不允许内网 URL，所以不传链接）。

## 对应接口（方便自己改）

| 模块路由（`/aurabot/api/ext/dfy-home/…`） | 干什么 |
| --- | --- |
| `GET /state` | 她的位置、动作、地点表、最近去过 |
| `GET /photo` | 拍一张，返回 `{ dataUrl }` 给面板显示 |
| `POST /goto` `{spot}` | 让她走到某个地点，等到位再返回 |
| `POST /command` `{type,...}` | 透传指令（`pat` / `feed` / `sleep` / `view` / `say` …） |
| `POST /open` | 起 dfy-room 服务并打开浏览器 |

dfy-room 侧的完整接口、curl 例子和排错表见它的 `docs/AURABOT.md`。
